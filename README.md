# 🔗 Linktree Portfolio — Shadow_Voidh

Uma página estilo **Linktree** moderna, responsiva e minimalista desenvolvida para centralizar links de redes sociais, projetos, portfólio e formas de contato em um único lugar.

🌐 **Acesse o projeto online:** [https://shadowvoidh.github.io/Linktree-Shadow_Voidh/](https://shadowvoidh.github.io/Linktree-Shadow_Voidh/)

---

## 📌 Sobre o Projeto

Este projeto foi desenvolvido como um agregador de links pessoal e profissional. Ele traz uma interface limpa, rápida e totalmente adaptada para dispositivos móveis e desktops, contando com navegação por rotas internas para políticas e termos de uso.

---

## 🛠️ Tecnologias Utilizadas

- **[React](https://react.dev/)** — Biblioteca para construção de interfaces
- **[TypeScript](https://www.typescriptlang.org/)** — Tipagem estática para maior segurança do código
- **[Vite](https://vitejs.dev/)** — Build tool ultra-rápida para ambiente de desenvolvimento
- **[Tailwind CSS](https://tailwindcss.com/)** — Framework CSS utilitário para estilização rápida e responsiva
- **[React Router DOM](https://reactrouter.com/)** — Gerenciamento de rotas com `HashRouter` (compatível com GitHub Pages)
- **[gh-pages](https://www.npmjs.com/package/gh-pages)** — Automação de deploy no GitHub Pages

---

## ✨ Funcionalidades

- 📱 **Design Totalmente Responsivo:** Excelente experiência em smartphones, tablets e computadores.
- 🎨 **Interface Dark Mode:** Visual moderno focado em usabilidade e legibilidade.
- 🔗 **Agregador de Links:** Acesso rápido ao GitHub, LinkedIn, Instagram, E-mail e Portfólio.
- 📄 **Páginas Institucionais:** Rotas integradas para *Política de Privacidade*, *Termos de Uso* e *Página 404 (Erro)*.
