# Política de Segurança

## Versões Suportadas

Apenas a versão mais recente em desenvolvimento na branch `main` recebe correções de segurança e atualizações.

| Versão | Suportada          |
| ------ | ------------------ |
| main   | :white_check_mark: |
| < 1.0  | :x:                |

---

## Como Reportar uma Vulnerabilidade

Se você encontrar alguma vulnerabilidade de segurança neste projeto (como exposição indesejada de dados, falhas de scripts ou chaves expostas), **não abra uma Issue pública**.

Por favor, faça o relato de forma privada através de um dos canais:

1. **E-mail:** Envie um e-mail com os detalhes para [shadow.voidh@gmail.com](mailto:shadow.voidh@gmail.com).
2. **GitHub:** Utilize a opção **Report a vulnerability** na aba **Security > Advisories** deste repositório (se ativa).

### O que incluir no seu relatório:
- Descrição do problema e qual parte do sistema é afetada.
- Passos detalhados para reproduzir a falha.
- Sugestão de correção (caso tenha uma).

---

## Processo de Correção

- **Confirmação:** O recebimento da mensagem será confirmado em até **48 horas**.
- **Resolução:** Após a análise e confirmação da falha, uma atualização de segurança será aplicada diretamente na branch `main` e publicada via GitHub Pages.
